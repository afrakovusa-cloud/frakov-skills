# Шаблон — юнит-экономика

Заполни по своему бизнесу. Цель — понять, зарабатываешь ли на ОДНОМ клиенте, до масштаба.

## Вход (твои числа)
- Цена за единицу/сделку: ______
- Переменные затраты на единицу (сырьё, доставка, комиссии, оплата эквайринга): ______
- Постоянные расходы в месяц (аренда, зарплаты, подписки): ______
- Средний чек / частота покупок: ______
- Срок жизни клиента (сколько месяцев/покупок остаётся): ______
- Месячный отток (для подписки), %: ______
- Расход на привлечение за период: ______
- Сколько платящих клиентов привёл за период: ______

## Расчёт
| Показатель | Формула | Значение |
|---|---|---|
| Маржа вклада на ед. | Цена − Переменные | |
| Валовая маржа % | (Цена − Переменные) / Цена | |
| Точка безубыточности, шт./мес | Постоянные / Маржа вклада | |
| CAC | Расход на привлечение / Клиентов | |
| LTV | Маржа с клиента × срок жизни (или маржа-мес / отток) | |
| LTV / CAC | LTV / CAC | |
| Окупаемость CAC, мес | CAC / Маржа с клиента в мес | |

## Диагноз
- **LTV/CAC < 1** → теряешь на каждом клиенте. Не масштабируй. Чини: ↑цену, ↑удержание, ↓CAC, ↑маржу.
- **LTV/CAC 1–3** → на грани. Масштаб рискован, сначала улучши экономику.
- **LTV/CAC ≥ 3 и окупаемость ≤ 12 мес** → можно лить в рост.
- **Высокий отток** → чини удержание раньше привлечения; дырявое ведро не наполнить.
- **Точка безубыточности недостижима при реальном объёме** → пересмотри цену или модель затрат.

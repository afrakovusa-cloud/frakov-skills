# Стартовый пакет — что нужно, чтобы продать первые 5 раз

Когда просят «всё для старта / упаковать / реклама, сайт, визитки» — собирать пакет **под первые продажи выбранной стратегии**, не на годы вперёд. Граница задаёт состав: «что нужно, чтобы продать первые 5 [единиц] к [дате]».

## Порядок из канона (важнее самого списка)
1. **Позиционирование первым** — Obviously Awesome (Dunford): «positioning is a fundamental input into ... every piece of content we create, every sales pitch we make» (`grep -in "every sales pitch" source-book/obviously-awesome.md`). Без него материалы — вслепую.
2. **Оффер с гарантией** — $100M Offers: материалы продают оффер, а не товар.
3. **Каждая точка контакта — часть прототипа** — The E-Myth Revisited: визитка, вывеска, цвета, форма — одна система, проверяется (`grep -in "business card" source-book/e-myth-revisited.md`).
4. **Каналы — тест 3 вероятных** — Traction (Bullseye), см. `functions/offer-gtm.md`.
5. **Учёт с первого дня** — The Lean Startup: таблица заявок = будущий baseline для `functions/simulation.md`.

Сам чек-лист ниже — операторская практика, вне книг.

## Чек-лист (брать нужное под нишу)
- **Основа:** позиционирование одной фразой; 1–2 оффера по сегментам; имя; домен.
- **Юридика РФ:** ИП/режим (`functions/taxes-ru.md`); ОКВЭД — основной под реальную деятельность + дополнительные (сверить с бухгалтером); 2 банка; касса, если платят физлица; договор с клиентом — две редакции отмены (физлицо / юрлицо); договоры с подрядчиками и агентами; политика ПД и уведомление РКН; рассылки только с согласия; правила площадок; права на ИИ-контент — всё по `functions/compliance-ru.md`.
- **Продающее:** КП по сегментам (PDF, 1 страница); прайс; портфолио **только настоящее** (до первых продаж — схемы и макеты, не чужие фото); гарантия текстом.
- **Деньги (Profit First):** пять счетов с первого дня — доходы, прибыль, владелец, налоги, операционные; сначала раскладка, потом счета; лист «План-факт» в таблице заявок.
- **Онлайн:** лендинг на 1 экран с формой/мессенджером; карточки Яндекс Карты и 2ГИС; площадки ниши (Авито, Яндекс Услуги, Profi); пост в своих соцсетях; **таблица заявок** (источник, статус, причина отказа).
- **Офлайн:** визитки с QR; листовка для партнёрских точек; метка бренда на месте оказания услуги.
- **Помещение (по согласию):** 4 ракурса + план с размерами, выходами и проверкой норм — `playbooks/помещение-3d.md`.
- **Партнёры:** список 20 тёплых контактов; скрипты по типам партнёров; агентские условия.
- **Операции:** стандарт выполнения (чек-лист), аварийные сценарии, что делать после заказа.

## Проверки перед выдачей
- Технические цифры в материалах сверены с источником (пример LED: потребление экрана 4×3 м — до 11 кВт, а не «розетка 220 В»).
- Юридическая проверка по `functions/compliance-ru.md`: отмена для физлиц, реклама и рассылки, персональные данные (включая зарубежные сервисы), правила площадок, права на ИИ-контент.
- Все пустые поля (телефон, реквизиты) перечислены владельцу списком.
- Печатные файлы — PDF нужного формата, 1 страница, проверены рендером.

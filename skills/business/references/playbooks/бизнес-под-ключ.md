# Бизнес под ключ — алгоритм старта: цель владельца → проверка → закупки → запуск

Когда владелец говорит «бизнес под ключ», «полный пакет», «сделай как с LED» — весь путь от сырой идеи до работающего старта. Этот файл — порядок, ворота и сборка. Содержание каждого шага живёт в своём файле (ссылки), здесь не копируется.

Каркас — из канона: программа развития бизнеса E-Myth (7 шагов: Primary Aim → Strategic Objective → Organizational → Management → People → Marketing → Systems Strategy; `grep -in "business development program" source-book/e-myth-revisited.md`), три вехи Lean Startup (MVP-baseline → tune → pivot/persevere; `grep -in "three learning" source-book/the-lean-startup.md`), каскад Playing to Win, пять счетов Profit First, правило 50% Traction.

Образец прохода: LED-экраны СПб, 2026-09-29 (`Приложения/Бизнес/2026-09-29 LED-экраны СПб — *.html`, папки `LED — стартовый пакет/`, `LED — закупки/` в vault).

## Проверки перед сдачей (каждая — прогоном, не на глаз)
- HTML: Playwright на 390 и 1000 px — без горизонтальной прокрутки, консоль чистая, интерактив прокликан (поля ввода не глушат горячие клавиши).
- Симулятор: `node --check`; ядро в node — цифры в отчёте = цифры модели.
- PDF: 1 страница нужного формата (A4, A5, 90×50) — считать страницы в файле, не по Spotlight.
- zip — Python `zipfile` (флаг UTF-8), иначе русские имена ломаются на телефоне.
- Отправка: забрать сообщение из Избранного, размер файла = размер на диске.
- Содержание: технические цифры — из паспорта оборудования; юридика — по `functions/compliance-ru.md` (отмена для физлиц, реклама и рассылки, персональные данные и зарубежные сервисы, правила площадок, ИИ-контент); портфолио только настоящее; имя/фамилию владельца не угадывать; все пустые поля — списком в `00`.

## Грабли прошлых проходов (LED, «Живая открытка»)
- Не спросили цель владельца (фаза 0) — стратегию выбрали по деньгам, не по его времени.
- Сравнение стратегий без остаточной стоимости — аренда нечестно выигрывает.
- Условный маршрут без правила решения — модель «покупает всегда».
- Потребление оборудования «на глаз» (220 В) вместо паспорта (до 11 кВт).
- Удержание всей предоплаты у физлиц — противоречит ЗоЗПП.
- «Дубль ссылки в SMS получателю» без согласия — реклама без согласия + чужие ПД («Живая открытка»).
- Данные клиентов в зарубежный ИИ без уведомления РКН о трансграничной передаче («Живая открытка»).
- Закупки без процедуры: «собрать 3–5 КП» без шаблона, б/у без протокола осмотра, валютный риск (курс +30% → кассовый разрыв в 100% прогонов) без защиты.

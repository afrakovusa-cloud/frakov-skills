# Полный бизнес-план — стандарт «готовый бизнес»

Когда просят план/«собери бизнес» — это НЕ список буллетов. Каждый раздел = **полный разбор по книге + конкретная рекомендация под этот бизнес**. Правило контракта (SKILL.md) действует в каждом разделе: метод из `source-book` (grep, назвать книгу) → применить к реальным данным → вывод.

## Формат каждого раздела (обязательный)
1. **Метод из книги** — какой приём, из какой книги (grep-якорь), 1–2 фразы сути из текста.
2. **Применение** — как приём ложится на ЭТОТ бизнес (с цифрами/данными из веба).
3. **Рекомендация** — конкретно что делать: «беру X, потому что Y». Не «можно рассмотреть» — решение.

Каждый раздел — абзац-разбор, не строчка. «Готовый бизнес» = человек читает и может исполнять.

## Стандарт глубины (ДЕФОЛТ — владелец подтвердил на разборе La Fete)
Любой разбор/план по умолчанию делать на этой глубине, не «кратко-буллетами». Эталон-образец — глубокий разбор La Fete (структура ниже). Держать формат:
1. **Диагноз** одним блоком (Rumelt: проблема → политика → действия), не просто «резюме».
2. **Рынок в цифрах** — TAM/объём, тренд (растёт/сужается), serviceable-доля. Пример: «Коми 4258 браков, −6.7%, Сыктывкар ~900–1000/год». Без цифр рынка разбор неполный.
3. **Конкуренты детально** — не список, а по каждому: позиция + данные + барьер (7 Powers) + где щель.
4. **Метки достоверности** у тезисов: `факт (источник, дата)` — только по первоисточнику нужного уровня (правило и ворота — `SKILL.md`, рабочий контракт п. 5) / `оценка` (рыночный ориентир, расчёт) / `гипотеза` (вывод) / `нужны-цифры` (внутреннее) / `не проверено` (источник не открылся). Не выдавать оценку за факт.
5. **Каждая рекомендация — с метрикой**: что делать + «как поймём, что сработало» (проверяемый признак).
6. **План роста** — приоритеты со сроками и ожидаемым эффектом (таблица), логика порядка.
7. **Раздел «что нужно от владельца»** — какие внутренние цифры превратят внешний разбор в финансовую модель.

Приём (скилл `phrases` №11/12): это формат-эталон вместо слова «качественно». Отклоняться — только если задача явно мельче.

## Обязательные числовые блоки
- **Стартовый капитал** — таблица разовых + подушка на кэш-разрыв.
- **Юнит-экономика** — чек, маржа вклада, точка безубыточности.
- **Путь к прибыли** — помесячно: выход на безубыток → прибыль → окупаемость.
- **Дорожная карта** — по неделям/месяцам, конкретные шаги.

- **Симуляция рисков** — если разовая ставка > 1 млн ₽ или сильная сезонность: веер P10/P50/P90, риск кассового разрыва, пороги, торнадо по `functions/simulation.md`.

## Грань (не раздуть в воду)
Глубоко — не значит длинно ради длины. Каждый раздел несёт РЕШЕНИЕ, подпёртое книгой и цифрой. Убери всё, что не двигает «что делать». Тяжёлые фреймворки бери там, где они реально нужны (малому бизнесу не нужен весь Porter) — но опора на книгу в каждом разделе обязательна.

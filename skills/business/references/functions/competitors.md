# Анализ конкурентов — где щель, а не лобовой бой

Цель: не «кто вокруг», а **где незанятая щель и не лезешь ли ты в лоб к тому, у кого барьер**. Плохой анализ = список конкурентов. Хороший = вывод, что тебе делать иначе. Опора: конкурентные альтернативы (Obviously Awesome), барьер/Power (7 Powers), диагноз чужой стратегии (Good Strategy).

## Максимум по книгам — методы-эталоны (для глубокого разбора)

Нужен серьёзный анализ — не импровизируй, а **иди по методам из книг** (тексты в `../source-book/`, грепай по якорям).

### A. 10-шаговый процесс позиционирования (Obviously Awesome, Dunford)
Полный метод; шаги 4–8 = ядро работы с конкурентами. `grep -in "10-step\|competitive alternatives" source-book/obviously-awesome.md`.
1. Понять клиентов, которые тебя ЛЮБЯТ (что они реально ценят).
2. Собрать команду позиционирования.
3. Согласовать словарь, отпустить «багаж» старого позиционирования.
4. **Список настоящих конкурентных альтернатив** — что клиент возьмёт, если тебя нет (часто «Excel»/«ничего», не прямой аналог).
5. **Выделить уникальные атрибуты** — что есть у тебя и НЕТ у альтернатив.
6. **Смапить атрибуты в ценностные «темы»** — что клиент из-за них получает.
7. Определить, **кто ценит это больше всех** — твой сегмент.
8. **Найти рыночную категорию (frame of reference)**, где твои сильные стороны в центре, и спозиционироваться в ней.
9. (Осторожно) наложить тренд. 10. Зафиксировать позиционирование.

### B. Оценка барьера конкурента (7 Powers, Helmer)
Прогони конкурента по **всем 7** — что из этого у него реально есть: `grep -in "counter-positioning\|switching costs\|scale economies\|network econom\|branding\|cornered resource\|process power" source-book/7-powers.md`.
1. Scale Economies · 2. Network Economies · 3. Counter-Positioning · 4. Switching Costs · 5. Branding · 6. Cornered Resource · 7. Process Power.
Нет ни одной → у него только фора по времени, щель есть. Есть барьер → в лоб не идёшь.

### C. Прочитать чужую стратегию (Playing to Win + Good Strategy)
- **5 выборов конкурента** (Playing to Win): его winning aspiration / where to play / how to win / способности / системы. `grep -in "where to play\|how to win" source-book/playing-to-win.md`. Видишь его «где играет» → выбираешь, где НЕ играет он.
- **Диагноз** (Good Strategy, Rumelt): в чём его слабое место расклада, бей туда согласованными действиями. `grep -in "diagnosis\|guiding policy" source-book/good-strategy-bad-strategy.md`.

Быстрый разбор (ларёк/точка) — шаги 1–5 ниже. Глубокий (продукт/рынок/раунд) — методы A–C выше по книгам.

## Шаг 1 — кто реально конкурент
Не только «такие же». Три круга:
- **Прямые** — та же категория (другая шаверма/кофейня рядом).
- **Косвенные** — закрывают ту же потребность иначе (столовая, доставка, «сварю дома», магазин у дома).
- **Альтернатива «ничего»** — клиент просто не покупает. Часто главный «конкурент».

*(Obviously Awesome — `source-book/obviously-awesome.md`, "competitive alternatives": начни с того, что клиент использует СЕЙЧАС, не с прямых аналогов.)*

## Шаг 2 — что собрать по каждому (наблюдаемое, без догадок)
Для локальной точки — реально добывается ногами и из карт:
| Что | Где взять |
|---|---|
| Цена, средний чек, ассортимент | меню, витрина, 2GIS/сайт |
| Место и поток | пройти в пик/не-пик, посчитать |
| Рейтинг + число отзывов | 2GIS, Яндекс.Карты |
| **На что жалуются** (золото) | читать 1–3★ отзывы |
| Очередь, скорость обслуживания | тайный покупатель, зайти в пик |
| Часы, загрузка | наблюдение |
| Сила бренда/лояльность | повторные клиенты, узнаваемость |

Правило: **факты, не «кажется сильный».** Рейтинг 4.8 при 600 отзывах ≠ 5.0 при 12.

## Шаг 3 — есть ли у него БАРЬЕР (не просто фора)
Прогнать конкурента через 7 Powers: чем он реально защищён?
- Место (захваченный ресурс — лучшая точка у потока),
- Бренд (платят за имя),
- Издержки переключения (карта лояльности, привычка),
- Масштаб (сеть давит ценой).
Есть барьер → **в лоб не идёшь**, ищешь другой сегмент/место/оффер. Нет барьера, просто первый пришёл → щель есть.

*(7 Powers — `source-book/7-powers.md`: "switching costs", "branding", "cornered resource".)*

## Шаг 4 — где дыра (твой вход)
Отзывы 1–3★ и наблюдение дают карту слабых мест: медленно в пик / грязно / невкусно стабильно / нет по утрам / хамят / нет безнала. **Каждая жалоба = твой потенциальный оффер.** Ищешь незанятую щель по: сегменту, времени, месту, скорости, качеству, цене.

*(Good Strategy — `source-book/good-strategy-bad-strategy.md`: диагноз — найди, в чём слабость расклада, и бей туда согласованными действиями.)*

## Шаг 5 — вывод (ради чего всё)
Одна страница: 
1. Кто сильный и чем защищён (не трогать в лоб).
2. Где щель (сегмент/место/время/боль из отзывов).
3. **Твой ход** — позиционирование в щель + 1–2 конкретных действия.
Если щели нет и всё занято сильными с барьером — **честный вывод «не сюда»** тоже результат (сэкономил деньги).

## Оценка проходимости (поток места) — прикинуть из данных, не только «иди считай»

Поток — цифра №1 для точки. Её можно **оценить заранее** по публичным прокси, а не оставлять пустой. Собери 2–3 источника → диапазон, не одно число. Помечай оценку датой.

Прокси (от дешёвого к точному):
1. **«Популярные часы» в 2GIS / Яндекс.Картах** — график загрузки конкурента/места по часам. Даёт форму пика и относительную интенсивность.
2. **Число отзывов конкурента ÷ срок работы** — грубый индикатор оборота: 600 отзывов за 2 года ≫ 30 за 2 года. Обычно отзыв оставляет малая доля (~0.5–2%) клиентов → можно прикинуть порядок.
3. **Официальная посещаемость ТЦ / БЦ** — арендодатель называет (или пресс-релизы «ТЦ X — N тыс. посетителей/день»). Дели на этажи/зоны для своей точки.
4. **Пассажиропоток транспорта** — отчёты города по маршрутам/остановкам (пример: Эжва 3,1 млн пассажиров/год). Остановка у точки = поток мимо.
5. **Обратный счёт от конкурента** — прикинь его продажи (по чеку, отзывам, очереди) → сколько людей его кормят → поток мимо места.
6. **Плотность населения + радиус охвата** — жителей в 1–1.5 км × доля-ходят × частота.
7. **Гео-аналитика** (2GIS Geomarketing, МТС/билайн аналитика) — точные счётчики, но платно; для крупной ставки.

**Триангуляция:** возьми 2–3 прокси, дай **диапазон** («~40–70 стаканов/день реалистично»), а не ложную точность. Финальная сверка — ручной замер: 15-мин срез в пик × коэффициент дня.

*(Это операционный метод разведки, не из книг канона — помечено честно. Книжная часть — что делать с потоком дальше: узел finance/operations.)*

## Ошибки узла
- Список без вывода «что мне делать».
- Копировать лидера → воюешь на его поле, где у него барьер.
- Считать конкурентом только прямых, забыть «ничего»/альтернативы.
- «Сильный на глаз» без цифр (рейтинг×отзывы, поток, чек).
- Игнорить отзывы-жалобы — там готовая карта их дыр.

## Когда сюда идти
Заходишь на занятый рынок; выбираешь место среди конкурентов; «уже кто-то это делает — стоит ли»; ищешь чем отстроиться от точки рядом.

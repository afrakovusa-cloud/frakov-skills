# Шпаргалка — формулы и правила

## Юнит-экономика
- **Валовая маржа** = (Выручка − Себестоимость) / Выручка
- **Маржа вклада на ед.** = Цена − Переменные затраты на ед.
- **Точка безубыточности (шт.)** = Постоянные расходы / Маржа вклада на ед.
- **CAC** = Расход на канал / Число привлечённых платящих
- **LTV** = Маржа с клиента за период × срок жизни (подписка: маржа-в-мес / месячный отток)
- **LTV / CAC** — здоровье ≥ 3; < 1 = теряешь на каждом клиенте
- **Окупаемость CAC** = CAC / Маржа с клиента в мес — комфорт ≤ 12 мес
- **Runway (мес)** = Деньги на счёте / Burn в мес

## Правила-эвристики
- **Прибыль — мнение, кэш — факт.** При разрыве смотри cash flow, не P&L.
- **Не масштабируй при LTV/CAC < 1.** Реклама на дырявую воронку = ускоряешь убыток.
- **Час на узком месте = час всей системы.** Оптимизируй ограничение, не всё подряд.
- **Спрос (узел 2) важнее операций (узел 3).** Не чини процесс без подтверждённого спроса.
- **Цену поднимай, пока не начнёшь заметно терять сделки.**
- **Стратегия без «где НЕ играем» — не стратегия, а цель.**
- **Преимущество без барьера копирования — фора по времени, не защита.**
- **MVP = минимум ради данных, не ради красоты.**
- **В кризисе выбирай наименее плохой вариант быстро; промедление хуже.**
- **Нанимай под силу под задачу, не под отсутствие слабостей.**

## Локализация сбоя «не растёт / не зарабатывает»
1. Стратегия — есть ли причина покупать именно нас (барьер)?
2. Оффер/привлечение — ценность > цены? есть повторяемый канал?
3. Операции — держится без основателя? где узкое место?
4. Финансы — сходится на единице? хватает кэша?
5. Люди — рычаг, найм, что ломается при ×10?
Иди по порядку. Верхние узлы важнее нижних.

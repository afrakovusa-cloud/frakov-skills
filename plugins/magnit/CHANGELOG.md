# Изменения

Формат: [SemVer](https://semver.org/lang/ru/). Пока 0.x — API сайта меняется без предупреждения,
ломающие изменения возможны в минорной версии.

## v0.1.0 — 2026-11-12

Первая публичная версия.

**Добавлено**
- `core/magnit_api.py` — корзина, поиск, цены, слоты доставки, превью заказа, баллы, купоны,
  промокоды, адреса, оплата, заказы, возвраты, подписка (40 команд).
- `core/magnit_api_probe.py` — снимок заголовков и куки живой сессии браузером.
- `core/magnit_search_probe.py` — разведка XHR поиска: адрес и тело запроса.
- `tools/` — браузерный запасной путь: корзина кликами, добавление по прямым ссылкам
  со сверкой через API, поиск в контексте точки, дамп корзины.
- `examples/magnit_watch.py` — страж цен по медиане прошлых дней.
- `docs/API_MAP.md` — карта 130+ путей API с пометками «проверено / пишет данные / не работает».
- `README.md` — установка и быстрый старт; `RUNBOOK.md` — пошагово плюс таблица ошибок;
  `OUR-SCRIPTS.md` — наши наработки и грабли.

**Не поддерживается**
- Оформление заказа: черновик отдаёт 422, следующий шаг — списание денег. Есть только превью.
- Работа с IP дата-центров: 403/498, нужен домашний выход или прокси.

**Известные ограничения**
- Куки протухают (дни–недели) — лечение: повторить снимок сессии.
- Цена и наличие привязаны к точке доставки, разница по магазинам одного города 5–29%.
- Весовой товар принимается кратно шагу товара.

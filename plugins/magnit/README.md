# Магнит без браузера — неофициальный клиент API

Скрипты, которые работают с сайтом доставки «Магнит» напрямую через его HTTP API: читают и
правят корзину, ищут товары, считают доставку, показывают акции, баллы и купоны, сравнивают
цены по ближайшим магазинам.

Главная идея: браузер нужен **один раз** — снять с живой сессии заголовки и куки. Дальше всё
идёт обычными запросами `requests` за 0,15–0,3 секунды вместо минут кликов.

```
снимок браузером (~2 мин, раз в несколько недель)
        ↓
~/.magnit/magnit_api_headers.json    ← заголовки + куки вашей сессии
        ↓
magnit_api.py --cart / --add / --slots / --compare …
```

## Что умеет

| Команда | Что делает |
|---|---|
| `--check` | жива ли сессия, та ли корзина |
| `--cart` | состав корзины: позиции, количество, сумма |
| `--add <код>…` / `--remove <код>…` | положить / убрать товары по кодам |
| `--weigh <код:грамм>` | весовой товар (кратно шагу товара) |
| `--find "<слово>"` | поиск по ассортименту точки: цена, остаток, ссылка |
| `--catalog "<слово>"` | что из этого есть на главной странице точки |
| `--compare "<товар>"` | цена товара по ближайшим магазинам |
| `--slots` | слоты доставки: цена, порог бесплатной, ближайшее окно |
| `--preview` | превью заказа: сумма, доставка, недоступные позиции |
| `--bonus` `--coupons` `--promocodes` | баллы, купоны (что сгорит первым), промокоды |
| `--orders` `--order <id>` | активные заказы и история, детали |
| `--addresses` `--payments` `--cards` `--transactions` | адреса, способы оплаты, карты, история баллов |
| `--subscription` `--returns` | подписка, возвраты |
| `--snapshot` `--deals` `--promos` | журнал цен, настоящие скидки, акции |
| `--cancel <id> --confirm` `--reorder <id> --confirm` | 🔒 отмена и повтор заказа |

Заказ **не оформляется** — скрипты останавливаются на превью. Оформление сознательно не
подключено: черновик заказа отдаёт 422, а следующий шаг — списание денег.

Карта API (130+ путей с пометками «проверено / пишет данные / не работает») — `docs/API_MAP.md`.

## Требования

- Python 3.9+, `pip install requests`
- Для снимка сессии и браузерных скриптов: `pip install playwright` + `playwright install chromium`,
  Linux с экраном или `xvfb-run -a` (headless режет антифрод сайта)
- Аккаунт на magnit.ru с выбранным адресом доставки

## Установка

```bash
git clone <этот-репозиторий> magnit-plugin
cd magnit-plugin
python3 -m pip install requests
# только если нужен снимок сессии и браузерный режим:
python3 -m pip install playwright && python3 -m playwright install chromium
```

Данные (снимок сессии, журнал цен, логи) хранятся в `~/.magnit/`.

## Быстрый старт

1. Снять сессию (откроется браузер, один раз):
   ```bash
   xvfb-run -a python3 core/magnit_api_probe.py
   ```
2. Проверить:
   ```bash
   python3 core/magnit_api.py --check
   python3 core/magnit_api.py --cart
   ```
3. Дальше — по таблице выше.

Подробно, со всеми ошибками и что делать: **[RUNBOOK.md](RUNBOOK.md)**.

## Грабли, о которых нужно знать заранее

- **Блок по IP.** С хостингов/дата-центров сайт отдаёт 403/498: подмена User-Agent и браузер не
  помогают, проверяется IP. Нужен домашний/мобильный выход или прокси (`MAGNIT_PROXY`).
- **Куки протухают.** Сессия живёт недели, иногда дни. Лечение — повторить снимок сессии
  (один запуск браузера), не перебирать заголовки руками.
- **Цена и наличие зависят от точки.** Разница по магазинам одного города — 5–29%. Товар можно
  положить в корзину, но в конкретном магазине его нет: остаток проверяется отдельно.
- **Вес кратен шагу.** У весового товара есть шаг (например, 500 г): 300 г даст строку «0 гр».
- **Оформление заказа не поддерживается** (см. выше).

## Структура

```
core/      ядро: запросы к API + снимок сессии браузером
tools/     браузерный запасной путь: корзина кликами, добавление по ссылкам
examples/  примеры для самостоятельных скриптов (страж цен)
docs/      карта API
```

## Проект не связан с «Магнит»

Неофициально, без поддержки сети. Работает с вашим собственным аккаунтом вашими же куками.
Автоматизация может противоречить пользовательскому соглашению сайта — решайте сами и не
делайте того, что вам не нужно. Гарантий нет: API меняется без предупреждения.

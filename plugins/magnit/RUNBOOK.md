# Ранбук: с нуля до рабочей корзины

Порядок шагов важен: каждый следующий предполагает, что предыдущий прошёл.

## 0. Установка

```bash
python3 -m pip install requests playwright
python3 -m playwright install chromium
```

Проверка, что Playwright жив:

```bash
python3 -c "from playwright.sync_api import sync_playwright; print('ок')"
```

## 1. Снимок сессии (один раз, потом по мере протухания куки)

Открывается настоящий браузер, вы уже залогинены (профиль `~/.magnit/profile` сохраняется),
скрипт ловит запрос корзины и сохраняет его заголовки и куки в `~/.magnit/magnit_api_headers.json`.

```bash
xvfb-run -a python3 core/magnit_api_probe.py
```

- Первый запуск: браузер откроется на magnit.ru — войдите и выберите адрес доставки.
- Скрипт печатает только имена заголовков и цифры, секреты на экран не выводит.
- Готово, когда в `~/.magnit/magnit_api_headers.json` есть `headers`, `cookies`, `url`.

## 2. Проверка сессии

```bash
python3 core/magnit_api.py --check
```

- «сессия жива» + номер корзины → всё в порядке, идём дальше.
- `401` / «сессия истекла» → шаг 1 заново.
- `403` / `498` → блок по IP, см. «Ошибки» ниже.

## 3. Выбор точки доставки

Цены, наличие и слоты считаются для конкретного магазина. Код магазина сайт держит в куке
`shopCode` (например `ВАШ_КОД_МАГАЗИНА`) и заголовке `x-store-code`.

```bash
python3 core/magnit_api.py --addresses      # ваши адреса и их id
python3 core/magnit_api.py --stores 5       # ближайшие магазины к адресу доставки
```

Смена точки на лету:

```bash
MAGNIT_STORE=<код магазина> python3 core/magnit_api.py --find "молоко"
```

## 4. Корзина

```bash
python3 core/magnit_api.py --find "молоко 2.5"     # найти код товара
python3 core/magnit_api.py --add <код> [<код>…]    # положить
python3 core/magnit_api.py --cart                  # проверить
python3 core/magnit_api.py --remove <код>          # убрать
python3 core/magnit_api.py --weigh <код>:2000      # весовой: 2 кг
```

Правило: после `--add` **всегда** смотреть `--cart`. API отвечает «ок» и на позицию, которой в
магазине нет, — она появится в корзине с количеством 0.

## 5. Оформление (не выполняется)

```bash
python3 core/magnit_api.py --slots      # цена доставки, порог, ближайшее окно
python3 core/magnit_api.py --preview    # сумма, доставка, недоступные позиции
```

Дальше — вручную на сайте. Скрипты сознательно не оформляют заказ.

# Ошибки и что делать

| Симптом | Причина | Лечение |
|---|---|---|
| `403` / `498` на всё подряд | блок по IP (хостинг, VPN, чужой город) | домашний/мобильный выход или `MAGNIT_PROXY=http://host:port`; UA и браузер не помогают |
| `401`, «сессия истекла» | протухли куки | повторить шаг 1 |
| «API отдал чужую корзину» | в снимке сессии оказался другой аккаунт/тип доставки | выйти из лишних аккаунтов, повторить шаг 1 |
| позиция в корзине с `0 шт` | товара нет в этом магазине | `--find "<товар>"` по точке, выбрать другую позицию |
| весовой товар «0 гр» | граммы не кратны шагу товара | повторить с шагом (500, 1000…) |
| цены в `--compare` прыгают | разные точки, акции на точку | сравнивать одну и ту же позицию по коду |
| пустой ответ поиска | запрос ушёл без `x-service: express` или чужой точкой | проверить заголовки в `~/.magnit/magnit_api_headers.json` |

# Обслуживание

- **Раз в неделю:** `--check`. Протухло — снимок сессии, 2 минуты.
- **Раз в месяц:** `--snapshot` (журнал цен) — база для `--deals`.
- **Логи:** `~/.magnit/magnit_api.log` — время, действие, код ответа, тело до 300 знаков.
- **Обновился сайт, путь отдаёт 404:** смотреть `docs/API_MAP.md` (там помечено, что
  проверено), затем `core/magnit_search_probe.py "<слово>"` — он ловит актуальный XHR поиска
  и показывает адрес и тело запроса.

# Безопасность

- `~/.magnit/magnit_api_headers.json` и `profile/` = ваш аккаунт. Не коммитить, не пересылать.
- Файл — обычный JSON с куками: доступ к нему = доступ к аккаунту магазина.
- Публичный репозиторий не содержит ни куки, ни токены, ни адреса доставки — проверяется
  перед каждым пушем: `grep -riE 'cookie|token|password' .`
